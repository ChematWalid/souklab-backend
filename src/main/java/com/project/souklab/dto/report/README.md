# Report DTOs

Contracts for reporting users, posts, and reviews and for administrator resolution actions.

| Class | Responsibility |
| --- | --- |
| [`ContentReportRequestDTO`](ContentReportRequestDTO.java) | Validated report target, reason, and details input. |
| [`ContentReportResponseDTO`](ContentReportResponseDTO.java) | Report queue and reporter-facing representation. |
| [`ReportResolutionRequestDTO`](ReportResolutionRequestDTO.java) | Administrator resolution action and note input. |
