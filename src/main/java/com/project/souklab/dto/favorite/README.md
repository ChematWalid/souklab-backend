# Favorite DTOs

Contracts for client favorite artisan responses, directory card items, and favorite status checks.

| Class | Responsibility |
| --- | --- |
| [`ClientFavoriteArtisanResponseDTO`](ClientFavoriteArtisanResponseDTO.java) | Response payload returned upon successfully favoriting an artisan. |
| [`ClientFavoriteArtisanItemDTO`](ClientFavoriteArtisanItemDTO.java) | Paginated list item pairing favorited timestamp with public `ArtisanDirectoryCardDTO`. |
| [`FavoriteStatusResponseDTO`](FavoriteStatusResponseDTO.java) | Status check response indicating whether an artisan is favorited. |
